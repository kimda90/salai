# Salai

Salai is an experimental DaVinci Resolve companion for scripted and footage-first video production.

The core idea is to keep **script, narrative intent, planned shots, captured/generated media, review notes, and Resolve timelines connected** throughout a project.

Initial direction:

- DaVinci Resolve remains the media, editing, Fusion, color, Fairlight, and delivery engine.
- Salai owns the production/narrative graph around Resolve.
- Projects can start either from a blank idea/script or from existing footage.
- Generative AI is treated as another source of production media: generate, ingest, review, edit, and finish normally.
- GenAI backends should be pluggable, starting with ComfyUI and a hosted multi-model provider.

This repository is currently in product/technical discovery.
