# Narrative Lenses

## Role

A Narrative Lens emphasizes one creative aspect of the **same Salai project**. It is not a second document, mandatory tab, or new state owner. A Projection is derived presentation; a Workspace stores chosen human organization around project objects. These ownership distinctions survive the narrative-first filmmaking pivot.

The main product interaction is [Tell → See → Direct → Update](filmmaking-interaction.md). Lenses support a current creative question rather than presenting the filmmaker with several applications to manage.

## Retained evidence

0B/0C demonstrated coherent Outline, Story Wall, AV Script, and Paper/Radio views over one project. That validates shared-state behavior, not a requirement to retain four primary navigation modes. 0B found routine manual structure management costly; 0D found mechanical semantic-level switching fragmented temporal context. See the [0B](spike-0b-assessment.md) and [0D](spike-0d-assessment.md) assessments.

## Useful emphasis in the new loop

| Creative question | Possible emphasis |
| --- | --- |
| What is this moment supposed to communicate? | Selected Beat/shot intent beside the viewer. |
| What happens before and after it? | Ordered story strip, outline, or contextual timeline. |
| What does this character/location look like? | Scoped references and the currently chosen description. |
| Which take should I use? | Candidate comparison with preserved previous selection. |
| Why does this output need review? | Recorded inputs and a readable change explanation. |
| Which material is sourced rather than authored? | Source identity and excerpt ranges. |
| Where should the actor/camera/light be? | Optional future shot staging view, not required setup. |

These are UI possibilities, not a mandate to implement seven panels or permanent lanes. Add an emphasis only when it improves a decision in the active slice.

## Interaction rules

Keep the relevant story visible when focusing on detail. Raw IDs, parent arrays, operation names, and generation plumbing stay hidden unless needed for debugging. Direct manipulation remains available when it is the natural way to direct; natural language is not a reason to remove useful controls.

Capture the target of feedback at submission, not at later model completion. A later selection change must not redirect a pending instruction. Agent and direct edits meet at the project service and appear through the same state. Canvas positions, viewport, filters, and playhead do not silently become story meaning.

## What not to build yet

Do not expose a global dependency graph, formal narrative-quality score, requirements matrix, or branch manager as the default filmmaking experience. “Narrative pulse” remains a metaphor, not a canonical score/object. Material readiness is not proof that a story intention has been communicated.

Standalone 0E's hierarchical editor is paused; useful parts may be adopted under the [active plan](filmmaking-implementation-plan.md). Supporting temporal semantics remain in [editorial-interaction.md](editorial-interaction.md).
