# @salai/script-model

Pure TypeScript implementation boundary for Spike 0A — Narrative IR.

This package exists to validate the Narrative IR independently from Electron, React, persistence, Resolve, editor frameworks, and AI integrations.

The implementation should follow `docs/narrative-ir-spec.md` and remain small enough that failed domain assumptions are cheap to change.

Initial work belongs here only if it directly helps test the Spike 0A pass/fail questions.
